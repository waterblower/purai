# Exp4 结果：WikiText-103 raw 与 TinyStories 对照

2026-09-25，在相同学习算法和训练参数下，将约 100 MB TinyStories 替换为 WikiText-103 raw。**完整 BLiMP 从 52.46% 提高到 54.86%，增加 2.40 个百分点。** 语料变化有帮助，但结果仍低于公开 5-gram 和 LSTM 参考。

## 实验与训练

| 项目 | TinyStories 100 MB（上一轮） | WikiText raw（本轮） |
|---|---:|---:|
| 结构训练正文 | 100,000,007 bytes | 100,007,723 bytes |
| 独立文档 | 113,035 篇故事 | 5,648 篇文章 |
| 训练轮数 | 12 | 12 |
| 匹配复制 | 关闭 | 关闭 |
| 节点数 | 96,729 | 103,816 |
| 模型文件 | 10,662,954 bytes / 10.17 MiB | 14,373,365 bytes / 13.71 MiB |
| 训练阶段（含逐轮验证） | 112.22 秒 | 131.17 秒 |
| 完整训练命令墙钟时间 | 139.54 秒 | 170.52 秒 |

本轮完整命令 user CPU 为 159.91 秒、sys CPU 为 5.99 秒。计时不含下载、转换和 BLiMP；完整命令包含读取输入、模型保存/重载、最终验证及 5-gram 对照。本轮 5-gram 构建和评估耗时约 37.74 秒。

`comparison.json` 自动核对了两份训练报告的全部 options 和 parameters，完全相同。本轮未修改 `src/`、根 Cargo.toml 或 Cargo.lock，只新增独立的数据转换工具、下载/实验脚本和报告。

第 12 轮仍新增 10,000 个节点，候选数量达到 100,000 上限，停止原因是轮数上限，不能视为收敛。本轮模型文件也比上轮大，因此这是同数据字节预算、同训练设置下的语料对照，不是同模型体积实验。

## 完整 BLiMP 对照

两次均为相同的 67,000 对句子，严格比较整句概率，关闭复制，不归一化长度。公开模型分数来自[BLiMP 作者修订后的逐任务结果](https://github.com/alexwarstadt/blimp/blob/3e56b06fcabca9b30822fc66435fca6b1aa40bb1/raw_results/summary/models_summary.jsonl)，未在本机运行参考模型。

| 模型 | 准确率 |
|---|---:|
| 随机猜测 | 50.00% |
| 本项目 TinyStories 10 MB | 51.60% |
| 本项目 TinyStories 100 MB | 52.46% |
| **本项目 WikiText raw 100 MB** | **54.86%** |
| 公开 word 5-gram | 61.24% |
| 公开 LSTM | 69.81% |
| 公开 Transformer-XL Large | 69.63% |
| 公开 GPT-2 Large（774M 参数） | 83.02% |

WikiText 模型答对 **36,758 / 67,000**，TinyStories 100 MB 模型答对 35,150，净增加 1,608 题。逐题对齐：12,488 题由错变对，10,880 题由对变错；共同答对 24,270 题，共同答错 19,362 题。WikiText 有 7 对完全同分，均按协议计错，另有 1 对接近同分。

| 语法类别 | TinyStories 100 MB | WikiText 100 MB | 变化（百分点） |
|---|---:|---:|---:|
| 反身代词一致性 | 59.15% | 47.15% | -12.00 |
| 论元结构 | 58.13% | 59.14% | +1.01 |
| 约束关系 / binding | 58.70% | 58.69% | -0.01 |
| 控制与提升 | 54.94% | 56.90% | +1.96 |
| 限定词—名词一致性 | 51.84% | 49.98% | -1.86 |
| 省略 | 30.20% | 46.55% | +16.35 |
| 填充语—空位依赖 | 60.09% | 62.29% | +2.20 |
| 不规则词形 | 61.40% | 60.00% | -1.40 |
| 孤岛效应 | 47.56% | 50.45% | +2.89 |
| 否定极性项许可 | 41.67% | 50.39% | +8.71 |
| 量词 | 49.18% | 51.98% | +2.80 |
| 主谓一致性 | 50.08% | 56.80% | +6.72 |

改善主要出现在省略、否定极性项、主谓一致性等类别，反身代词一致性明显下降。不能把总体提升解释成已经学到了稳定、普遍的语法规则。

字节长度诊断中，正确句较短、等长、较长三个子集的准确率分别为 66.37%、49.28%、50.26%。等长子集仍接近随机；三个子集的类别构成不同，这只是诊断，不替代标准总体分数，也不能单独归因于长度偏差。

## 本域验证和生成

WikiText 官方验证集为 60 篇文章、1,145,236 字节。

- graph_only：**1.853385 BPB**。
- 同训练输入的固定 byte 5-gram：**1.848424 BPB**。
- 本域的固定 5-gram 略优于这轮图模型。日志还输出 with_match 的辅助值，但本实验不将其作为结果，因为训练和主要评测关闭复制。

该验证集不同于 TinyStories 的验证集，不能把 1.853385 与先前的 1.270810 直接比较。论文表格中的 word 5-gram 又是另一模型，不能和这里的 byte 5-gram 混同。

训练程序已验证保存后重载的模型与内存中模型完全一致；固定提示词的生成命令也成功执行，完整结果保存在 `sample.txt`。样本表现出百科文本风格和局部可读词串，句子连贯性仍弱；没有只筛选好看的输出。

## 可比性和复现

使用相同的训练轮数、搜索预算、平滑参数和完整 BLiMP 协议；数据规模的 0.008% 以内差异来自保留完整文章边界。WikiText 与 TinyStories 的领域、词汇、文档长度和空格/标点格式同时变化，不能进一步归因为某一个因素。raw 语料仍保留 WikiText 的预处理痕迹。

公开模型使用不同训练数据和预算，这些分数只是外部能力参考。当前模型只使用最多 12 个字节的上下文；这次没有扩展结构表达能力，没有按 BLiMP 选 checkpoint，也没有做污染审计或统计显著性检验。

所有模型输出、日志与本轮报告均在本目录；输入在 `../data/`，已被 gitignore 排除。此前被 Git 跟踪的训练 JSONL 已移出索引，本地文件保留；既有共享验证集未改动。
