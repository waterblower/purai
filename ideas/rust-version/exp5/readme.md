# V5：有状态的离散程序学习原型

本版本将候选模型从固定后缀查表扩展为可执行程序：程序可以保存文档状态、绑定值、访问关联记忆、调用共享模块和执行有预算的循环。训练搜索程序结构与组合方式。它是研究原型，尚未训练，不能据此宣称达到 Transformer 的语言能力。

## 目录与运行

`code/` 是独立 Rust crate，`experiment/` 用于新实验产物。`legacy-wikipedia-scaling/` 完整保留此前的 Wikipedia 实验，与新架构不是同一模型。

以下命令均从 `rust-version/exp5/code/` 执行，供后续获准训练时使用：

```sh
cargo run --release -- train --input ../../data/train.jsonl --output ../experiment/v5.model --report ../experiment/train.json
cargo run --release -- infer --model ../experiment/v5.model --prompt 'Once upon a time,' --n 200
cargo run --release -- eval --model ../experiment/v5.model --input ../../data/test.jsonl --report ../experiment/test.json
cargo run --release -- train --resume ../experiment/v5.model --input ../../data/new.jsonl --output ../experiment/v5-next.model
cargo run -- inspect --model ../experiment/v5.model
```

`--help` 列出完整参数。默认输入文件上限为 64 MiB，更大输入需显式设置 `--max-data-bytes`；程序不会悄悄截取前缀。模型和报告拒绝覆盖已有文件。模型采用带版本、长度及 SHA-256 的二进制封装，内部载荷为 JSON，与旧模型不兼容。

## 原子结构与学习范围

固定解释器提供 16 个寄存器、整数/字节串、条件分支、字节操作、关联记忆读写、受限循环、模块调用和预测提案。程序的 observe 阶段接收真实历史字节并更新状态；predict 阶段只能读取历史状态，在临时寄存器上计算，不可写持久记忆。每个字节先预测再观察，文档边界清空运行状态。

训练会搜索候选程序、修改指令和分支、调整后缀长度、增删预测专家、调整执行顺序及停止阈值，并将重复程序块提取成共享模块。输出可以是某个字节的提案，也可以是一个特征键所对应的学习分布；多个专家与根分布进行概率混合。内部循环不需要输出草稿字节。

搜索起点是人工编写的程序模板：后缀特征、分隔符驱动的关联记忆、十进制整数运算；分隔符候选来自语料，随后进行有限预算变异。这些是明确的归纳偏置，并不等于自动发现任意算法或自然语言语义。关联记忆可以跨越较长的无关历史，但能否从自然语言训练出有用的读写规则尚未验证。

## 选择目标与数据协议

输入不经过外部 tokenizer。JSONL 支持字符串、`{"text": "..."}` 或 `{"bytes": [0,255]}`；其他扩展名作为一个原始二进制文档。完全相同的文档按 SHA-256 去重，不进行近重复或 benchmark 污染审计。

默认按文档确定性划分训练、校准和选择集，约为 80/10/10；单个原始文档先切分为三个片段，每段重置运行状态。`--validation` 提供外部选择集。训练数据拟合统计，校准集选混合权重，选择集用于结构决策，因此训练日志中的 BPB 不是独立测试结果。最终泛化必须另外通过 `eval` 测试。

结构选择目标由选择集 BPB、模型序列化长度惩罚和平均计算工作量惩罚组成。长度是 JSON 存储成本代理，不是最优编码长度。默认最多 24 轮，每轮 16 个候选；还受总工作量与时间预算限制。可用 `--stop-on-bpb-increase` 在首次选择集 BPB 增加时停止并保留此前模型；未完成的搜索轮不提交。

## 资源与增量学习

寄存器值、记忆条目/字节数、程序燃料、专家数量和模型大小都有显式限制。默认最多 8 个专家、每个值 4096 字节、每个专家 2048 个记忆项；FIFO 淘汰意味着远处知识不保证永久保留。过长字段可能使该专家在当前文档余下部分失效；预测失败则回退到其他分布。

报告包含 BPB、工作计数、指令数、失败/耗尽、淘汰、跳过专家和状态内存估算，并记录进程峰值 RSS 与 CPU 时间。工作计数是计费代理，不是实际 CPU 指令数；时间限制是协作式检查。观察阶段仍执行所有活跃专家，尚未实现完全稀疏的学习路由。

续训保存按文档计数凭据以及有限回放样本，防止同一文档重复计数，并在结构选择时考虑旧样本。它不能保证零遗忘；凭据元数据也会随文档增加。只有内容寻址模块注册表的集合合并满足 CRDT 式交换、结合和幂等性，整个训练模型与搜索过程不具备该保证。

## 与目标的差距和验证状态

已实现容量增删、程序结构搜索、共享模块、跨历史状态、内部可变计算及字节输入的机制。尚未证明有效的自然语言抽象、百万 token 上下文能力、知识量与模型体积成比例、无遗忘或接近 LLM 的效果。也没有保证计算越多预测必然更好。

非训练测试覆盖远距离关联记忆、状态重置、整数运算、内部循环、资源限制、因果约束、概率归一化、模块合并和文件完整性。这些测试使用显式构造的程序，证明运行语义，不证明训练能找到这些程序。端到端程序搜索测试标记为 ignored；按要求没有执行训练，也没有新训练模型或 benchmark 结果。

```sh
cargo test --offline
cargo clippy --offline --all-targets -- -D warnings
```

不要使用 `--ignored`，除非准备明确启动训练测试。
