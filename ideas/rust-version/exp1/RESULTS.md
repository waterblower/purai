# 本次训练与验证结果

使用提供的 `data/train.jsonl` 和 `data/validation.jsonl`，采用默认参数。未根据验证结果挑选超参数或最佳轮次；报告第 12 轮结束后的最终模型。

## 数据与协议

| 用途 | 文档数 | 字节数 |
|---|---:|---:|
| 原始训练数据 | 11,459 | 10,000,592 |
| 实际结构学习与上下文计数 | 10,886 | 9,291,403 |
| 训练侧复制可靠度校准 | 573 | 709,189 |
| 独立验证 | 1,286 | 1,000,375 |

校准集是训练记录的末尾 5%（向上取整），因此不等于训练字节数的 5%。各文档独立计数、匹配和评估，不在故事之间连接历史。验证集不参与任何持久状态更新。JSONL 文件 SHA-256 见 [validation-run.json](validation-run.json)。

## 验证指标

bits/byte 越低越好。以下配置使用同一个最终模型；固定 n-gram 对照使用相同的结构训练文档及 `discount=0.75, theta=2`。

| 配置 | 验证 bits/byte | 上下文步骤/字节 |
|---|---:|---:|
| 只使用根分布 | 4.387699 | 1.00 |
| 学到的图，最多 4 步，关闭复制 | 1.863881 | 3.97 |
| 固定 5 阶 n-gram | 1.432128 | 未计量 |
| 学到的完整图，关闭复制 | 1.407565 | 6.28 |
| 学到的完整图，启用校准复制 | **1.368834** | 6.28 |

“上下文步骤”仅计根访问和槽位匹配测试，不是 CPU 指令数，也不含复制匹配器、概率运算和模型加载。完整图在本验证集上的每字节步数范围为 1–13。各配置均预测相同数量的字节；增加内部遍历预算不会增加输出长度。

5 阶 n-gram 是一个明确固定的对照，并未搜索最佳阶数。本实验不能据此声称超过最好的 n-gram、Transformer 或现有压缩器。关闭复制的对照表明，图本身在该协议下也优于这个固定 5 阶对照；未做关闭合并的独立消融，因此尚不能分离合并带来的泛化收益。

## 学到的结构

- 初始：1 个根节点。
- 12 轮累计：新增 29,201 个节点，接受 682 次叶子合并，裁剪 189 个叶子。
- 最终：28,331 个节点，其中 547 个节点使用共享字节类，最大上下文深度 11。
- 模型文件：2,609,857 字节，约 2.49 MiB。
- 首次记录的结构学习、逐轮验证与校准合计约 9.54 秒；不包含最后的基线训练。

每轮节点数：

```text
74 → 864 → 4,875 → 13,080 → 21,206 → 26,145
→ 27,920 → 28,397 → 28,482 → 28,447 → 28,393 → 28,331
```

后几轮新增收益减弱，合并使总体积下降。共享类包含类似 `{Q|q}` 的大小写关系，也包含并不具有明显语义意义的字节组合；它们是局部预测分布相近的假设，不能解释为已发现稳定的自然语言概念。

## 复现与运行开销

从 `rust-version/` 运行：

```sh
cargo run train --input data/train.jsonl --output output.model
cargo run infer --model output.model --prompt "Once upon a time,"
cargo run eval --model output.model --input data/validation.jsonl
```

本机为 macOS / arm64，工具链 Rust 1.97.1，使用启用 `opt-level=2` 的开发 profile。缓存构建后重复执行完整默认训练命令，包含逐轮及最终验证、模型保存和重新加载、5 阶 n-gram 训练与评估：

- 命令成功退出，墙钟时间约 12.40 秒。
- 子进程峰值 RSS 为 740,032,512 字节，约 705.75 MiB；包含该命令中的模型缓存和基线工作，不是模型文件大小。
- 两次训练输出的模型逐字节相同。
- 模型 SHA-256：`05208e4643478c965eab0a392570d25cdd8227b1dd0309f3e696e9fbb1f1e02b`。

运行开销来自一次本机重复测量，不代表跨机器的性能保证。确定性已在相同平台和工具链上验证，不承诺不同平台浮点库下的结构搜索逐位一致。

完整逐轮指标保存在 [output.report.json](output.report.json)，重复运行的命令、退出码、资源测量和数据校验值保存在 [validation-run.json](validation-run.json)，交付源码校验值保存在 [source-sha256.json](source-sha256.json)。

## 固定提示词生成

预设三个提示词，均使用 400 个续写字节、温度 0.85、种子 42。全部样本保存在 [samples.json](samples.json)，没有依据文本质量筛选。

第一个提示词是用户要求的 `Once upon a time,`。其开头为：

```text
Once upon a time, there was like a bit scared. They kept on the bird called Amy and drove to cry.
The cows, but Tom and Snail the water with feel his eyes!
```

模型学到了故事语料中的局部拼写、常用表达和一些上下文关系，但语法、人物一致性和情节连续性仍然较差。不同提示词在相同随机种子下还会出现重复的续写片段，反映当前有限局部上下文对长期主题的控制不足。

这些结果验证了模型能训练、生成、改变拓扑、共享统计，以及在相同输出长度下使用不同计算预算；没有验证通用推理、程序归纳或 LLM 级别的文本生成能力。
